# Reinforcement Learning

> **Ringkasan:** Paradigma ML di mana agen belajar melalui interaksi dengan environment menggunakan reward/punishment.

## Konsep Utama

- **Agent:** Pembuat keputusan
- **Environment:** Dunia tempat agen berinteraksi
- **Action:** Tindakan agen
- **Reward:** Sinyal umpan balik
- **Policy:** Strategi agen

## Contoh

Game AI, robotika, self-driving car.

## Algoritma

Q-Learning, PPO, A3C, DQN
