# Underfitting

> **Ringkasan:** Model terlalu sederhana sehingga tidak mampu menangkap pola dalam data.

## Tanda-tanda

Training error dan test error **sama-sama tinggi**.

## Solusi

- Gunakan model lebih kompleks
- Tambah fitur (feature engineering)
- Kurangi [[Regularisasi]]

## Hubungan dengan Konsep Lain

- Terkait: [[Overfitting]], [[Bias-Variance Tradeoff]], [[Learning Curve]]
