# Unsupervised Learning

> **Ringkasan:** Paradigma ML di mana model menemukan pola dari data **tanpa** [[Label]].

## Tipe Task

| Task | Tujuan | Algoritma |
|------|--------|-----------|
| **Clustering** | Pengelompokan | [[K-Means]], [[DBSCAN]], [[Hierarchical Clustering]] |
| **Dimensionality Reduction** | Kurangi fitur | [[PCA]], [[t-SNE]], [[UMAP]] |
| **Anomaly Detection** | Deteksi anomali | [[Isolation Forest]], [[Autoencoder]] |

## Hubungan dengan Konsep Lain

- Terkait: [[Supervised Learning]], [[Reinforcement Learning]]
- Evaluasi: [[Silhouette Score]]
