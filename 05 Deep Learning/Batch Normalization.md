# Batch Normalization

> **Ringkasan:** Normalisasi input setiap layer selama training untuk stabilisasi.

## Efek

- Mempercepat training
- Mengurangi internal covariate shift
- Bertindak sebagai regularizer ringan (mirip [[Dropout]])
