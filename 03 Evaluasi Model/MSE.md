# MSE

> **Ringkasan:** Rata-rata kuadrat selisih prediksi dan aktual. Menghukum error besar lebih berat.

## Rumus


$$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$
