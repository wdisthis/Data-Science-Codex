# R-Squared

> **Ringkasan:** Proporsi variansi target yang dijelaskan oleh model (0-1).

## Rumus

`R2 = 1 - SS_res / SS_tot`

## Interpretasi

- R2 = 1 â†’ model menjelaskan semua variansi
- R2 = 0 â†’ model tidak lebih baik dari rata-rata
- R2 < 0 â†’ model lebih buruk dari rata-rata (possible)
