# Type I dan Type II Error

> **Ringkasan:** Dua jenis kesalahan dalam pengujian hipotesis statistik.

## Definisi

| Error | Nama Lain | Deskripsi |
|-------|-----------|-----------|
| **Type I (alpha)** | False Positive | Menolak H0 padahal H0 benar |
| **Type II (beta)** | False Negative | Gagal menolak H0 padahal H0 salah |

## Analogi

- **Type I:** Alarm kebakaran berbunyi padahal tidak ada api
- **Type II:** Alarm kebakaran tidak berbunyi padahal ada api
