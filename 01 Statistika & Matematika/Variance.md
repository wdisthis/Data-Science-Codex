# Variance

> **Ringkasan:** Rata-rata kuadrat selisih setiap titik data dari mean â€” mengukur sebaran data.

## Rumus

`Var(X) = sigma^2 = SUM(xi - mu)^2 / N`

- Untuk **populasi:** bagi dengan N
- Untuk **sampel:** bagi dengan N-1 (koreksi Bessel)
