# Data Manipulation Language

> **Ringkasan:** Kumpulan perintah SQL yang digunakan untuk mengelola data di dalam tabel.

## Definisi

**Data Manipulation Language (DML)** adalah kumpulan perintah SQL yang digunakan untuk melakukan operasi pada data yang ada di dalam tabel, seperti menambah, mengubah, menghapus, dan mengambil data.

## Perintah Utama DML

| Perintah | Fungsi | Link Detail |
| :--- | :--- | :--- |
| **SELECT** | Mengambil/menampilkan data dari tabel | [[SELECT]] |
| **INSERT** | Menambahkan data baru ke dalam tabel | [[INSERT UPDATE DELETE#INSERT]] |
| **UPDATE** | Memperbarui data yang sudah ada | [[INSERT UPDATE DELETE#UPDATE]] |
| **DELETE** | Menghapus data dari tabel | [[INSERT UPDATE DELETE#DELETE]] |
