# Inference

> **Ringkasan:** Menggunakan model yang sudah dilatih untuk membuat prediksi pada data baru.

## Training vs Inference

| Fase | Aktivitas |
|------|-----------|
| **Training** | Model belajar [[Parameter]] dari data |
| **Inference** | Model memprediksi output dari input baru |
